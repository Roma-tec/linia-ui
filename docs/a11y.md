# Доступность

Цель будущего интерфейса — WCAG 2.1 AA. Прототип проверяет визуальные и навигационные решения; он не доказывает доступность программной реализации.

| Критерий | Требование | Способ проверки |
|---|---|---|
| Обычный текст | Контраст от 4.5:1 | Расчёт конкретных пар в tokens/contrast.json |
| Крупный текст | От 3:1 | 24 px regular либо 18.66 px bold |
| Активное состояние | Подпись и граница, не только цвет | Слои, выбранная вкладка, текущая история |
| Фокус | Кольцо 3 px, отступ 2 px | Образец в UI-ките; будущая Tab-проверка |
| Нажатие | Предпочтительно 44 × 44 px | Геометрия hotspot; небольшие видимые значки расширяются невидимой зоной |
| Модальное окно | Заголовок, отмена, возврат фокуса | В Figma показан выход; focus trap — задача реализации |
| Масштаб | Сохранение читаемости при увеличении | Перекомпоновка по брейкпоинтам, не уменьшение всего экрана |
| Движение | Короткие переходы без мигания | Dissolve 180 мс; вариант без анимации для реализации |
| Холст | Текстовое описание документа | Название, размер, активный слой и список объектов |

## Семантика для разработчика

Панель инструментов — toolbar, переключаемый инструмент — button с aria-pressed. Вкладки — tablist/tab/tabpanel с единым порядком фокуса. Уведомление — status, ошибка ввода — alert либо связанная через aria-describedby подпись. Поля имеют видимые label, а не только placeholder. Рисунок не должен быть единственным способом узнать структуру документа.

Для слоёв сохраняется текстовое имя. Кнопка глаза имеет название «Скрыть слой Горы» или «Показать слой Горы», а не «глаз». Проверка screenreader, реального клавиатурного обхода и сенсорного ввода проводится после реализации; в этой лабораторной эти испытания не проводились.
