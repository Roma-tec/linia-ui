# Тексты интерфейса

Тон спокойный, конкретный, без обещаний несуществующей функции. В действиях используются глаголы, в статусах — результат. Термины: проект — редактируемая работа, документ — открытая работа, изображение — экспортированный результат.

| Контекст | Текст | Следующее действие |
|---|---|---|
| Пустой список | Здесь начинается новая работа | Создать проект / открыть шаблоны |
| Новый документ | Новый проект | Название, размеры, создать |
| Неверный размер | Размеры должны быть от 64 до 2048 px | Исправить ширину и высоту |
| Слой | Активный слой: Горы | Выбрать другой или изменить |
| Фильтр | Фильтр применён · можно отменить | Открыть историю |
| История | Действие отменено | Продолжить либо повторить |
| Сохранение | Проект сохранён | Продолжить работу |
| Экспорт | PNG · с прозрачностью | Указать имя и скачать |
| Завершение | Изображение скачано | Вернуться к рисунку |
| Администратор | Участник заблокирован | Вернуться к списку |

Размеры записываются через знак ×: 960 × 600 px. Проценты отделяются пробелом: 100 %. В названиях команд не смешиваются русский и английский. Сообщение об ошибке располагается у поля. Название файла и название проекта могут совпадать, но имеют разные подписи.

## Граница прототипа

В Figma сообщения «сохранён» и «скачано» обозначают демонстрацию конечного состояния. На защите нужно это объяснить: файл не загружается, пароль не проверяется сервером, произвольное изображение не обрабатывается. Эти технические пояснения размещаются в описании прототипа, а не заполняют каждую кнопку интерфейса.
