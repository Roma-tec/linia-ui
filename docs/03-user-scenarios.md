# 3. Пользовательские сценарии

| № | Роль и цель | Основной путь | Ошибка / альтернатива | Результат |
|---|---|---|---|---|
| UC1 | Гость входит | Вход → демо → проекты | Регистрация → пустой список | Открыто пространство пользователя |
| UC2 | Новичок создаёт рисунок | Проекты → новый проект → размеры → холст | Размер 0 → подсказка → исправление | Появился документ |
| UC3 | Новичок берёт шаблон | Шаблоны → выбрать формат → использовать | Вернуться к проектам | Холст с основой |
| UC4 | Пользователь рисует | Кисть → размер → цвет → холст | Слой скрыт → включить видимость | Мазок на активном слое |

| UC6 | Пользователь применяет эффект | Фильтры → тёплый свет → результат | Отмена через историю | Изменён рисунок |
| UC7 | Пользователь отменяет | История → отменить → предыдущее состояние | История пуста → действие недоступно | Возвращено состояние |

## 3.2. Подробные сценарии

**Создание рисунка.** Предусловие: открыты проекты. Пользователь нажимает «Новый проект», видит имя и размеры, подтверждает создание. Ветка ошибки демонстрирует недопустимый размер. Пользователь исправляет параметры и попадает на холст. Постусловие: видит название, инструменты, активный слой и статус.

**Слои.** Предусловие: документ открыт. На вкладке «Слои» выбирается «Горы». Выделение указывает активный объект. Кнопка видимости изменяет состояние, а кнопка добавления создаёт отдельное состояние «Слой изменён». При демонстрации важно показать, что изменение слоя не меняет документ целиком.

**Экспорт.** Предусловие: изображение подготовлено. «Экспорт» открывает диалог с именем, форматом и размерами. PNG объясняется как формат с прозрачностью. После «Скачать» прототип показывает завершение. В Figma настоящий файл не формируется: тестируется понимание пути, а не кодирование изображения.

**Отмена эффекта.** После фильтра пользователь переходит в историю, нажимает «Отменить», видит подтверждение и продолжает работу. Результат — демонстрация возврата к предыдущему виду. Нельзя заставлять пользователя искать отмену в настройках аккаунта.

## 3.3. Сокращение длинных путей

| Длинный путь | Проектное сокращение | Зачем |
|---|---|---|
| Файл → меню → экспорт → формат | Кнопка экспорта в шапке | Частый конечный шаг доступен сразу |
| Переход на отдельную страницу эффекта | Вкладка панели возле холста | Не теряется контекст рисунка |
| Вручную создавать размеры публикации | Шаблоны трёх форматов | Меньше повторного ввода |
| Искать историю в общих событиях | Вкладка «История» в редакторе | Разделение документа и аккаунта |

## 3.4. UML Use-Case

Диаграмма `UML_UseCase.svg` находится в приложении к отчёту. Акторы: новичок, продвинутый пользователь, администратор. Продвинутый наследует базовые сценарии новичка; администрирование отделено от доступа к рисункам. Диаграмма показывает цели взаимодействия, а не подробные нажатия кнопок.
