# 11. Адаптивность, доступность и тексты

## 11.1. Адаптивность

Desktop 1440 × 960: инструменты 64 px, правая панель 296 px. На ноутбуке боковые панели должны сжиматься или сворачиваться до вкладок. На планшете параметры активного инструмента остаются над холстом, панель открывается по запросу. На телефоне 390 × 844 навигация инструментов переносится вниз, таблицы превращаются в карточки.

Desktop и смартфон представлены самостоятельными макетами. Добавлены четыре планшетных экрана в двух темах и обе ориентации мобильной рабочей области. Подробное поведение описано в responsive.md. Горизонтальная прокрутка всей оболочки запрещена, прокрутка содержимого холста допустима.

## 11.2. Доступность

Обычный текст — контраст от 4.5:1; крупный — от 3:1. Контраст надо считать по конкретным парам, а не по одному цвету палитры. Активный слой отличается обводкой и названием. Видимость обозначается отдельным символом с текстовым названием для реализации. Фокус 3 px, цели нажатия от 44 px. Изображение должно иметь описание вне холста для пользователей вспомогательных технологий.

Порядок клавиатурного обхода: шапка, инструменты, параметры, панель, статус. Диалог должен удерживать фокус, закрываться Escape и возвращать фокус в исходную кнопку. Figma-прототип не доказывает корректность будущей клавиатурной навигации и программы чтения с экрана.

## 11.3. Контент

| Ситуация | Текст |
|---|---|
| Пустой список | Здесь начинается новая работа |
| Неверный размер | Размеры должны быть от 64 до 2048 px |
| Сохранение | Проект сохранён |
| Экспорт | Изображение скачано |
| Фильтр | Фильтр применён · можно отменить |
| Отмена | Действие отменено |

Глагол описывает действие, а ошибка — способ исправления. Не обещать отправленное письмо или облачную синхронизацию без сервера. Не путать название файла и название проекта. Вместо «ошибка 400» использовать понятное объяснение.

## 11.4. Лицензии и авторство

Дизайн, композиция «Новый горизонт» и документация созданы для этой работы. Шрифт Inter распространяется по SIL Open Font License, текст лицензии входит в `assets/fonts/`. Исходники старого PixelForge и ФинКомпаса не использованы. Сборочные инструменты Node.js воспроизводят макеты и отчёт, но не составляют приложение графического редактора.
