# 2. Исследование

## 2.1. Метод и ограничения

Использован аналитический разбор задач и знакомых моделей графических редакторов. Интервью, полевое наблюдение и количественные опросы не проводились. Персоны ниже — проектные гипотезы. Нельзя представлять их как результаты реального исследования. Перед защитой полезно добавить собственные снимки актуальных версий конкурентов.

## 2.2. Аудитория

| Группа | Задача | Препятствие | Решение интерфейса |
|---|---|---|---|
| Студент без опыта | Сделать открытку или учебную иллюстрацию | Боится испортить работу, не понимает панели | Шаблоны, простая кисть, заметная отмена |
| Автор публикаций | Подготовить изображение нужного размера | Повторный ввод размеров, поиск экспорта | Пресеты форматов, экспорт в верхней панели |
| Любитель рисования | Собирать рисунок из частей | Теряет активный слой | Выделение активного слоя, видимость, порядок |
| Администратор учебной среды | Менять статус участника | Риск раскрыть чужие данные | Отдельная панель без изображений |

Персона Анна, 20 лет: оформляет студенческое мероприятие, хочет получить изображение за короткую сессию. Критерий успеха — сама создаёт проект и находит экспорт. Персона Михаил, 28 лет: рисует для блога, знает слои и хочет быстро менять порядок элементов. Критерий — понимает, какой слой активен и как отменить эффект.

## 2.3. Конкурентные модели

| Решение | Полезный паттерн | Риск для новичка | Вывод для «Линии» |
|---|---|---|---|

## 2.4. Устройства и ограничения

Мышь обеспечивает точное позиционирование; палец требует крупных областей. Перо может поддерживать давление, но наличие такой функции нельзя предполагать на любом устройстве. Широкий экран допускает постоянную правую панель, смартфон — только активную панель. Слабое устройство ограничивает размер документа и количество снимков истории. В прототипе выбран пример 960 × 600 px, а для создания предлагаются размеры 64–2048 px.

## 2.5. Выводы

Начало должно предлагать два пути: пустой проект и шаблон. Холст не теряется при смене панели. Тема оболочки нейтральна относительно цветов рисунка. История относится к документу, а не к списку всех действий пользователя. Экспорт объясняет формат, размеры и прозрачность. Эти решения требуют проверки с начинающими пользователями, а не только проверки наличия переходов.
