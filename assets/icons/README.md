# Пиктограммы «Линии»

Оригинальные 8 символов: кисть, ластик, прямоугольник, текст, плюс, слои, экспорт и закрытие. Сетка 24 × 24. Лицензия MIT, как у проекта.

Отдельные SVG и `sprite.svg` содержат заполненные контуры. В реализации спрайт подключается через `use href="sprite.svg#brush"`. В макетах также используются стандартные текстовые символы, поэтому набор передаётся как предложение разработчику, а не как точная замена всех глифов.

`linia-icons.ttf` и `linia-icons.woff2` содержат тот же набор в Private Use Area U+E000–U+E007. Таблица соответствий — `map.json`. Для внедрения объявить font-face с семейством `Linia Icons`, установить нужный код символа, скрыть декоративный глиф от screenreader и добавить понятное имя кнопке. Шрифт не заменяет доступную подпись.

Пересборка: `python tools/icons.py` из корня проекта (fonttools, brotli).
